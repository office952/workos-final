# Admin Resources UX migration V1

`/admin/resources` now uses the accepted WorkOS admin catalog grammar.

## What changed

PageHeader, compact counts, one read-only notice, category → item → detail, Materiale / Servicii / Manoperă / Dovezi de cost, rate + unit first, provenance chips from current classifications, IDs under Detalii.

## What did not change

Resource identity, families, specifications, cost evidence, recipes, rates, EIC, Product, Execution, People. No writes.
