# UI20-R5 — Smart modularity

Continuity must not depend on HUB-only capabilities.

| Company shape | What stays coherent |
| --- | --- |
| Advanced production | Lucrare → Atelier → Execuție |
| Small / manual | Cerere → Config → Ofertă still closes commercially |
| Machines unused | Atelier already shows a blocked row without a dedicated machine |
| Execution disabled | Ofertă frozen remains an artifact; LUC does not have to open a station |
| Later enablement | same IDs, new surface, no new object model |
| Other ProductTemplates | same handoffs; materials come from Product Truth, not UI |

If Execution is off, the commercial journey remains: CER → CONFIG → OFT freeze.
