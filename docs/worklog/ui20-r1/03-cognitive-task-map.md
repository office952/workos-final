# UI20-R1 — Cognitive task map

Lane A. What the operator must perceive, decide, and do. Not a sitemap.

## Perceive

| Moment | Must be obvious without reading H1 |
| --- | --- |
| Where am I | Destination + object identity + journey position |
| What is this object | Kind (cerere / ofertă / lucrare / resursă) + code + name |
| What state is it in | Needs-input / complete / current / blocked / silent |
| What is selected | One primary selection. Context follows it |
| What is missing | The blocking fact, not a generic error |
| What is silent | Unselected module does not appear as a failed module |

## Decide

| Decision | Owner of truth | UI must not invent |
| --- | --- | --- |
| Which product / template | Product System + catalog | Parallel product entity |
| Which roles are sold | Order configuration | Hidden calculators |
| Depth / technical values | Canonical component settings | Intake literals |
| Commercial price | Commercial | Resource rates |
| Can this operation start | Eligibility + plan | Fake capacity |
| Accept this quote | Reviewed snapshot | Recompiled later draft |

## Act

| Action class | Pleasure rule |
| --- | --- |
| Find | Registry + command/recent. Do not reconstruct filters |
| Open | Object workspace. Preserve return |
| Configure | Context lens or progressive section — measured in the form lab |
| Confirm | Exact reviewed definition |
| Dispatch | Atelier starts work; does not execute it |
| Execute | Focused, few exits |
| Price / quote | Read frozen commercial decision |
| Administer | After journeys. Product System is administration of construction truth |

## Pressure

Under operational pressure the UI must keep:

1. Object identity still
2. Journey position still
3. Cause of block visible
4. Next honest action visible
5. No mental rebuild of “where was I”

## Smart modularity (cognitive)

| Company | What must disappear | What must remain |
| --- | --- | --- |
| Advanced production | Nothing relevant | Capability, machines, eligibility |
| Small / manual | Empty machine / process destinations | Same object journeys |
| Module disabled | Navigation + surfaces for that module | No tombstone pages |
| Module enabled later | Same IA, newly audible | No company-specific fork |
