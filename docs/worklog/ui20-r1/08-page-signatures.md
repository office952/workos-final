# UI20-R1 — Page signatures

12 concept cards. Personality is **not** color, icon, or hero.

```text
PAGE_SIGNATURE_COUNT = 12
```

| Page | COGNITIVE_JOB | VISUAL_SIGNATURE | PRIMARY_PRIMITIVE | PRIMARY_ACTION_MODEL | DYNAMIC_BEHAVIOR | Recognizable without H1 |
| --- | --- | --- | --- | --- | --- | --- |
| Home | Orient + next honest action | Quiet launch / recent objects | Launchpad or next-action stack | Open / resume | Recent + blocked count, not KPI tiles | You see **what to do**, not a dashboard |
| Clients | Find a relationship | Registry of people/companies | Registry + identity | Open hub / new request | Filter persistence | Rows feel like **relationships**, not jobs |
| Request | Completeness of a commercial start | Object workspace + missing facts | Object + progressive completeness | Complete / configure | Needs-input → next | A **gap list**, not a product tree |
| Configurator | Confirm exact sold definition | Construction / lens | Context lens or construction | Confirm definition | Selection → settings | Parts and silence. No price. |
| Quote | Read a frozen commercial decision | Document-like commercial | Snapshot reader | Send / accept path | Immutability (little motion) | Money + freeze. Not editable construction. |
| Job | Own the production instance | Object + lineage | Object workspace | Prepare / open atelier | Related objects | The **work** after commerce |
| Atelier | What can start | Dispatch inbox | Dispatch list | Start / assign | Eligibility attention | Startable operations, not a shop map |
| Execution | Do the current operation | Focused, few exits | Focused execution | Complete step | Planned vs actual | One job in hand |
| Resources | Rate truth / ledger | Ledger / table | Ledger | Add / edit rate | Versioned rate, no price | Numbers as **cost evidence** |
| Machines | Identity + capability + eligibility | Capability workspace | Capability node | Bind / declare area | Module silent when unused | Machines as **capability**, not asset cards |
| People | Who may do what | Eligibility workspace | Eligibility | Assign / qualify | Skill depth optional | People as **eligibility**, not HR |
| Product System | Administer construction truth | Construction admin | Construction + settings | Inspect / (later) persist | Same geometry as configurator | Admin of **how products are built** |

Reject: tinted headers, unique icons as the only difference, hero banners.
