## Fatals

- **A:** 768 + pleasure. Can feel like a lab if hairlines dominate human work.
- **B:** Industrial credibility + expert density. Generic SaaS risk is the highest of the four.
- **C:** Atelier/Execuție may become articles. Focus ring as underscore is weak for 44px / visible focus.
- **D:** Mobile + company map + Lucrări invariant. Implementation realism is a fatal if treated as the OS.

## How to choose later (Owner, not Cursor)

1. Discard any direction with a fatal that cannot be repaired without becoming another direction.
2. Prefer the direction that can host **twelve different page signatures** without collapsing to cards.
3. Prefer the direction that survives no-color + 44px + focus.
4. Arithmetic mean is forbidden as the decision.
