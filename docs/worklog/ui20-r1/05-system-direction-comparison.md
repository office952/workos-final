# UI20-R1 — System direction comparison

These are **mini design systems**, not finished WorkOS pages. Cursor does not select a winner.

| Dir | Name | Node | Feel | Question left open |
| --- | --- | --- | --- | --- |
| A | Precision Industrial | `6:2` | Hairline, IBM Plex, geometry, density without default cards | Sophisticated, or sterile lab? |
| B | Calm Operational | `7:2` | Warm paper, Inter, rounded groups, visible journey | Precise enough for expert production? |
| C | Technical Editorial | `8:2` | Source Serif 4 + Plex, rules not cards, document you act on | Operational, or a report viewer? |
| D | Continuous Object Tool | `10:132` | Object never becomes “a page”; command + inspector | Novelty, or a better WorkOS job? |

Each A/B/C specimen includes: shell, registry, object workspace, journey, contextual config, operational fragment, state matrix, type/density, dark, motion storyboard.

## What is structurally different

- **A** treats selection as a geometric relation. Chrome is structural.
- **B** treats grouping as human workshop furniture. Chrome is softer; journey is louder.
- **C** treats the object as a readable technical document. Chrome almost disappears.
- **D** (if built) treats WorkOS as a tool: the object stays; destinations recede. This is an IA+visual hybrid, not a fourth paint job.

## Fatal weaknesses (not averages)

| Dir | Fatal if… |
| --- | --- |
| A | Pleasure dies; feels like a laboratory; 768 becomes a compressed CAD window |
| B | Expert density dies; becomes consumer SaaS; industrial credibility fails |
| C | Interactive controls feel like annotations; Atelier/Execuție become articles |
| D | Company map disappears; `/` Lucrări invariant is silently replaced; mobile becomes a command palette |

## Desktop / mobile

A/B/C were drawn first at desktop specimen width. Mobile fragments belong on the same boards or as companion 390 frames. R1 must show that the **philosophy** survives 768, not that every control is pixel-final.

## Transfer vs reject vs A3.1

A is the closest heir of A3.1. That is a risk (sunk-effort gravity) and a strength (already proven reading). B and C exist to force A to compete. D exists only if it is not A-with-command.
