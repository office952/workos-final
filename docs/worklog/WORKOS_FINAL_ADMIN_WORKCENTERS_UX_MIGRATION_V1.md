# Admin Workcenters UX migration V1

`/admin/workcenters` now uses the accepted WorkOS admin catalog grammar. Visible label: Utilaje și zone.

## What changed

PageHeader, compact counts, one read-only notice, zone → equipment → detail, workcenter-only posts vs machines, honest no-provider gaps, IDs under Detalii. Capability, LETTERS coverage and recipe maps are no longer top-level categories.

## What did not change

Workcenter and machine identity, capabilities, provider derivation, LETTERS composition, Execution, People, rates, EIC. No writes. No capacity, scheduling or maintenance.
