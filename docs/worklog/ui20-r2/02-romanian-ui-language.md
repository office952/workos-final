# UI20-R2 — Romanian UI lexicon

```text
USER_FACING = ROMANIAN + DIACRITICS
TECHNICAL_KEEP = CNC LED UV RAL CAD SVG DXF RGB
NOT_CANON = these are research labels, not domain owners
```

## Prefer in specimens

| Avoid (EN / calque) | Prefer when natural |
| --- | --- |
| workflow / job / stage | flux / traseu / lucrare / etapă |
| ready | pregătit |
| needs input | necesită informații |
| finish | finisaj (material) / finalizează (acțiune, rar) |
| backlit / frontlit | iluminare halou / iluminare frontală |
| work order | fișă de producție / lucrare |
| return | înapoi |
| Client hub | Client / fișă client |

## Operational verbs (research-accepted)

Debitare · Frezare · Îndoire · Formare · Asamblare · Lipire · Cablare · Montare LED · Testare · Laminare · Decupare · Colantare · Măsurători · Montaj · Verificare · Ambalare · Pliere · Sudură · Aplicare · Nesting.

## Commercial / marketing (reject as chrome)

Impact · premium · spectaculos · transformăm ideile · lux · cotație de vis · factory cost · 360°.

## Command-layer Romanian

Caută client… · Deschide cererea… · Deschide lucrarea… · Mergi la Atelier · Creează client · Configurează produsul.

Destructive actions stay out of the command list unless consequence is explicit.

## Length

Design for „Configurează produsul”, „necesită informații”, „lipsește operator eligibil”, „specificație comercială înghețată” — not English short-labels.
