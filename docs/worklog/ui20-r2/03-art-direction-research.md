# UI20-R2 — Art-direction research

Systems, not styles to clone.

| SYSTEM | BORROW | REJECT |
| --- | --- | --- |
| Ulm / Otl Aicher | Systematic grammar, wayfinding, repeatable primitives | Lufthansa livery, 1972 palette as brand |
| Rams / Braun | Interface as instrument, few controls, meaningful color | Retro radio fetish, knobs as ornament |
| Tufte | Dense layered reading, less container chrome | Chartjunk, sparklines as decoration |
| Schematic transit maps | Semantic relation over literal geography | Metro-map as the OS |
| Isotype | Repeatable pictographic vocabulary | Cute icons as personality |
| Swiss / New Typography | Type + grid as architecture | Poster rigidity on shop-floor |
| Japanese Ma | Negative space that means something | Museum emptiness |
| Constructivist energy | Controlled energy only in active transitions | Revolution theatre, fake diagonals |
| Teenage Engineering | Professional delight, tight control-feedback | Toy synth, dark gadget UI |

WorkOS may not look like any of these. It may share their **discipline**.
