# Manual geometry truth completion V1

Confirmed operator geometry is valid Product Truth. Analyzer is not required for current LETTERS EIC quantities.

## Contract

```text
confirmed FACE area
confirmed VOLUME perimeter
= valid Product Truth
```

Source of measurement ≠ validity after confirmation.

FACE / VOLUME no longer attach `Geometrie din Analyzer` when measurements exist.
Missing measurements stay honest: `Suprafață față neconfirmată` / `Perimetru volum neconfirmat`.

EIC stays PARTIAL when cost evidence is still provisional (`DEVELOPMENT_DEFAULT`, `LEGACY_EVIDENCE`, `PILOT_INTERNAL_EVIDENCE`, `AI_DECISION`).

Canonical none/none remains 595.00 EUR PARTIAL for calibration, not Analyzer.
