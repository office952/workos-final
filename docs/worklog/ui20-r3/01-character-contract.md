## DNA used as constraint

Calm under pressure. Precise without cold. Dense where comparison needs density. Focused where action needs focus. Romanian-first. Object stays. State has consequence. Normal is quiet. Exception is visible. Pages are different instruments.

Old operational pattern kept: the object stays, the work surface changes, the next valid action is clear, technical detail appears only when relevant.

## Fabrication verbs

CUT, FORM, LAYER, ALIGN, LIGHT, TRACE, FIT, FREEZE are conceptual. They do not appear as English UI labels or decorative motifs.

Visible Romanian translations only where the job benefits: confirmă / lipsește / blocat / eligibil / înghețată / proveniență.

## Refusals

Screens refuse ERP clone, MES clone, CAD, sign-shop website, developer tool, museum, portfolio, and generic premium SaaS.

## Content law

User-facing copy is Romanian with diacritics. Long strings were designed: Configurează produsul, Necesită informații, Pregătește pentru producție, Necesită utilaj dedicat, Iluminare frontală, Resurse și costuri. Atelier does not show assignment language.

Avoided in visible UI: workflow, job, stage, ready, needs input, finish, return, frontlit, backlit.

Kept: CNC, LED, RAL (not selected on this specimen), SVG/DXF unused.

LETTERS facts are fixture-safe: Plexiglas opal 3 mm, aluminiu 0,6 mm, Forex 10 mm, adâncime 60 mm, iluminare frontală. Commercial line uses existing 624,82 EUR. Resource rates use owner-confirmed catalog amounts. No invented stock, supplier, selling price on Resurse, or named machine.
