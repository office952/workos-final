# UI20-C1 — Administration

```text
GLOBAL_LEFT_SIDEBAR = NO
LOCAL_ADMIN_NAVIGATOR = ALLOWED_IN_REAL_COLLECTION
MARKETPLACE_TILES = NO
SETTINGS_DUMP = NO
```

Admin home is a quiet domain index grouped by Comercial / Operațiuni / Atelier / Sistem. Each line is a consequence, not a product tile.

Local navigator examples:

- People: Oameni | Calificări
- System: Sistem produs | Module | Guvernanță | Stare sistem

Governance and System Status stay quiet destinations. They may be reached from Admin. They do not inherit Atelier intensity.

Customer admin is lifecycle (add / rename / retire). Daily relationship work stays on Clienți / Client Hub.

Date firmă is seller identity on new quotes, not a global company settings dump.

Operational services remain modular: disable stops new selections only.
