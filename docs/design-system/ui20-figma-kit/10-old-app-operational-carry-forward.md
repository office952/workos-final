## OLD_APP_CARRY_FORWARD

Operational principles only (not visual inheritance):

1. **Clear next action** — empty and blocked states say what to do next.
2. **Role-aware landing** — operator attention ≠ owner admin tree.
3. **Operator focus** — workshop surfaces shrink chrome so work stays dominant.
4. **Dense scan surfaces** — production lists are scannable, not card galleries.
5. **Master/detail where selection persists** — quotes/clients keep the list while working the object (as a page pattern, not a global sidebar).
6. **Strong operational state visibility** — current / blocked / next are visible without debug chrome.
7. **Broad capability awareness** — hide what the org cannot do; do not show empty Coming Soon trees.

## OLD_APP_DO_NOT_CARRY

- Permanent global sidebar as the product identity
- COMPAT / AUDIT / PREVIEW badges
- Live DB chrome
- Developer tooling in operator nav
- Giant settings tree
- Compiler vocabulary as operator UI
- Permanent debug banners
- Decorative alert noise
- English/Romanian mix in operator chrome
- 50–100 item sidebar that becomes the page
